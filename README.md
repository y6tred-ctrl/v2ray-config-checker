# 🚀 V2Ray Config Checker

Автоматическая проверка рабочих v2ray конфигов с использованием GitHub Actions!

## 📋 Что это?

Этот репозиторий автоматически проверяет доступность репозиториев с v2ray конфигами каждый час и сохраняет результаты.

## ⚙️ Как это работает?

1. **GitHub Actions** запускает скрипт каждый час (по расписанию Cron)
2. **check_configs.py** проверяет каждый репозиторий из спика в `sources.txt`
3. Результаты сохраняются в:
   - `WORKING_CONFIGS.md` - красивый список с информацией
   - `results.json` - полные данные в JSON формате

## 📝 Как добавить новый источник?

1. Открой файл `sources.txt`
2. Добавь новую строку в формате: `owner/repo`
3. Например: `username/v2ray-configs`
4. Сохрани изменения
5. Скрипт автоматически проверит новый источник при следующем запуске

## 📊 Результаты проверки

После каждой проверки смотри:
- 📄 [WORKING_CONFIGS.md](WORKING_CONFIGS.md) - основной результат
- 📦 [results.json](results.json) - для программного использования

## ⏰ График проверок

Проверки запускаются:
- **Автоматически**: Каждый час (по UTC)
- **Вручную**: Перейди на вкладку "Actions" → выбери workflow → нажми "Run workflow"

## 📚 Популярные источники V2Ray

- **V2RAYCONFIGSPOOL/V2RAY_SUB** - Обновляется каждые несколько минут
- **ebrasha/free-v2ray-public-list** - Проверенный список, обновляется каждые 15 минут
- **barry-far/V2ray-Config** - Стабильный источник, обновляется каждые 15 минут
- **Epodonios/v2ray-configs** - Множество протоколов, обновляется каждые 5 минут

## 🔧 Технические детали

- **Язык**: Python 3.11
- **Зависимости**: requests, pyyaml
- **Расписание**: Cron: `0 * * * *` (каждый час)
- **Платформа**: GitHub Actions (Ubuntu latest)
